#  Blaze Kitchen

A modern, responsive restaurant landing page built with **React**, **Tailwind CSS**, and **Swiper.js** — designed to showcase a premium dining experience with smooth interactions and a clean UI.

## Features

-  **Fully Responsive** — Seamlessly adapts to mobile, tablet, and desktop screens
-  **Interactive Sliders** — Smooth touch-enabled carousels powered by Swiper.js (best selling, reviews, etc.)
-  **Modern UI Design** — Clean, visually rich layout using utility-first Tailwind CSS
-  **Component-Based Architecture** — Modular and reusable React components
-  **Smooth Scroll & Navigation** — Intuitive single-page navigation experience
-  **Hero Section** — Full-width visually engaging banner to capture attention
-  **Menu Showcase** — Highlighted dishes with descriptions and visual cards
-  **Reviews Slider** — Customer reviews displayed in a swipeable carousel

## Getting Started

### Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/Willie3011/Blaze-Kitchen.git
   ```

2. **Navigate to the project directory**

   ```bash
   cd Blaze-Kitchen
   ```

3. **Install dependencies**

   ```bash
   npm install
   ```

4. **Start the development server**

   ```bash
   npm run dev
   ```

5. **Open your browser** and visit `http://localhost:5173`

---

## Build for Production

```bash
npm run build
```

The optimized output will be generated in the `dist/` folder, ready for deployment.

To preview the production build locally:

```bash
npm run preview
```
